# For the Mahon.

Windows x64, English only currently - but should work fine with non-english games (Only checked Spanish so-far)

Be aware that some functions (like colonisation scouting) can pull down a lot of data and might take several minutes. It currently does this once a week (only when first accessed)

Initial startup will back-process your journals. This might take a little while.

If you want to push updates to raven colonial, set your key in the settings -> colonisation; only ONE client should push to raven, so don't do this if you are using one of the others.

Very much a project in current development; so treat accordingly. I use it for all my day-to-day play. This is a 'limited-release' for now until it's a more complete project.
