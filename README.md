# For the Mahon.

Windows x64, English UI only currently - but should work fine with non-english games (Only checked Spanish so-far)

Be aware that some functions (like colonisation scouting) can pull down a lot of data and might take several minutes. It currently does this once a week (only when first accessed)

Initial startup will back-process your journals. This might take a little while.

If you want to push updates to raven colonial, set your key in the settings -> colonisation; only ONE client should push to raven, so don't do this if you are using one of the others.
There's a few other settings that you should probably check off; such as if you have a power perk active on your squadron and if you make use of alt accounts depending on how you have that setup.

Current modules:
- Journal
- Surface mining (tweaked)
- Space mining (recent)
- Colonisation (tweaked)
- BGS & PP (tweaked)
- Trading (recent; modes for profit, bgs, merits)
- Exploration

Things marked (recent) have only been recently added and likely have a lot of rough spots that need sorting. More so than the rest of it.
Tweaked items have had smaller changes/fixes/additions made.

Very much a project in current development; so treat accordingly. I use it for all my day-to-day play. This is a 'limited-release' for now until it's a more complete project.
